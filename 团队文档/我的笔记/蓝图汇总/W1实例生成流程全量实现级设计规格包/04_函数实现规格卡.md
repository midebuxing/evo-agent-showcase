# 九段函数实现规格卡

> 跨包权威源与负向不变量见：`../_封口总则_字段权威源与负向不变量.md`。如本章与总则冲突，以总则和字段所属包权威章节为准。


本节是 `03_九段函数总览.md` §2 的逐函数展开。§2 给出 9 段函数总览（函数名 / 输入 / 输出 / 前置依赖），本节为每段单独一张实现规格卡，补上 §2 没列的字段：边界条件、噪声、公式、Reject 条件（P0）、Repair 动作（P1-P3）。

读者按需切换：要看跨段顺序看 §2，要看单段实现细节看本节。各段的公式 detail 回指 W0 spec 06（surrogate 公式），P0/P1/P2/P3 优先级体系完整定义见 `07_约束与四级修复.md` §1。

**P0-P3 速查**（完整定义在 `07_约束与四级修复.md` §1）：

| 优先级 | 含义 | 触发时动作 |
|---|---|---|
| **P0** | reject_or_resample | 拒绝并重采，整次生成丢弃 |
| **P1** | repair_world_truth_geometry_or_state | 修世界真相（几何 clamp / 重算 flag）|
| **P2** | repair_measurement_rounding_or_bounds | 修测量数值（rounding / clamp 到 unit bounds）|
| **P3** | projection_fallback_to_unknown_or_not_applicable | projection 层 fallback；**只在 法规映射层触发，不属 W1** |

## 1. `generate_building_world_bundle`

| 项 | 规格 |
|---|---|
| 输入 | `archetype_id`, `seed`, `config`, `registries` |
| 输出 | `WorldBundle`（含 BuildingContext / ComponentNode[] / LocationNode[] / FragmentContext[] / CoverageRelation[] / DriverState[]）|
| 边界条件 | 至少 1 个 building、1 个 component、1 个 fragment；所有 component 必须有 location；所有 fragment 必须引用 component / location |
| 噪声 | storey_count / area / component count 使用 bounded integer / continuous sampling |
| 公式 | `component_count ~ UniformInt(range_by_archetype)`；`fragment_area_m2 ~ TruncatedLogNormal(template.area_range)`；`accessibility_prior -> access_class` |
| Reject (P0) | component / material / location 不兼容；fragment_area <= 0；graph contains cycle |
| Repair (P1/P2) | P1 clamp geometry proxy；P0 graph cycle reject；P2 missing optional relation set default |

来源：`01_a12_权威旧蓝图.md`:L1036-L1096

## 2. `generate_structural_external_condition`

| 项 | 规格 |
|---|---|
| 输入 | fragment / component / location / driver |
| 输出 | MechanismState + ConditionState |
| 边界条件 | compatible component / material only；condition extent 不得超过 fragment geometry |
| 噪声 | mechanism score 加 `Normal(0, 0.03~0.05)` |
| 公式 | crack_score / spall_score / detachment_score；详见 W0 spec 06 §3 (structural / external surrogate) + §1.3 (crack coefficient table) |
| Reject (P0) | spall / rebar on non-RC；forced condition 下 crack score 低于 activation threshold；extent overflow |
| Repair (P1/P2) | P1 clamp extent / depth；P0 reject incompatible material；P2 round derived measurement later |

来源：`01_a12_权威旧蓝图.md`:L1100-L1165

## 3. `generate_drainage_fault`

| 项 | 规格 |
|---|---|
| 输入 | component / driver / params / rng |
| 输出 | `DrainageState`（含 misconnection / blockage / leakage / public_health_risk_index）|
| 边界条件 | `component_type` 必须属于 drainage component（drainage_stack / drainage_branch / floor_trap）；`segment_type` 必须兼容 location |
| 噪声 | blockage / leakage index 加 `Normal(0, 0.05)` |
| 公式 | 详见 W0 spec 06 §5 (drainage surrogate) |
| Reject (P0) | non-drainage component；public_health_risk_index > 0 但 causes 全为零 |
| Repair (P1) | P1 clamp risk `[0, 1]`；P0 reject non-drainage |

## 5. `generate_fire_safety_deficiency`

| 项 | 规格 |
|---|---|
| 输入 | component / driver / params / rng |
| 输出 | `FireSafetyState`（含 deficiency_present / deficiency_class / severity）|
| 边界条件 | 仅 fire-safety component（fire_door / fire_resisting_wall / escape_route / smoke_vent / fire_service_installation / unknown_fire_component）|
| 噪声 | severity `Normal(0, 0.04)` |
| 公式 | 详见 W0 spec 06 §7 (fire-safety surrogate) + spec 06 §7.X 6 个 importance weights (escape_route=1.0 / fire_door=0.9 / fire_resisting_wall=0.9 / smoke_vent=0.85 / fire_service_installation=0.85 / unknown_fire_component=0.7) |
| Reject (P0) | non-fire-safety component；deficiency_present=false but deficiency_class non-null |
| Repair (P1/P2) | P2 if deficiency_present=false set deficiency_class=not_applicable；P1 clamp severity |

## 6. `generate_coverage_sampling_measurements`

| 项 | 规格 |
|---|---|
| 输入 | fragment / coverage relation / plan / params / rng |
| 输出 | `MeasurementRecord[]`（coverage / sampling family）|
| 边界条件 | inspected_area <= fragment_area；covered_area <= fragment_area；ratio `[0, 1]` |
| 噪声 | ratio observed = true_ratio + `Normal(0, coverage_abs_noise)` |
| 公式 | 详见 W0 spec 06 §8 (coverage / sampling) + spec 06 §8.2 chain derive（DEBT-020 Round 5 sub-task 2 升 A 类）|
| Reject (P0) | negative area；ratio outside `[0,1]` after repair impossible；missing fragment area |
| Repair (P1/P2) | P1 clamp area；P2 clamp ratio；P2 round count nonnegative |

## 9. `derive_risk_repair_verification_flags`

| 项 | 规格 |
|---|---|
| 输入 | `WorldBundle`, registries |
| 输出 | `RepairAssessmentState[]` + derived flags（risk_building_safety_emergency / risk_public_health_emergency / risk_public_danger_present / repair_required / repair_outcome_safe_until_next_cycle / maintenance_pre_next_cycle_required / investigation_fsp_below_required_safety / verification_test_failed / coverage_insufficient / 等）|
| 边界条件 | 派生 flag 引用的 risk / repair / verification 输入必须在 W0 `risk_derivation_registry` / `repair_outcome_registry` / `verification_test_registry` 中注册 |
