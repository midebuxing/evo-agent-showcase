# 测量噪声三层合约

W1 measurement 派生（Step 6/7/8）+ sidecar measurement 派生时使用的噪声机制。本节是 W0 spec 06 §13/§14 + a12 §8 在 W1 阶段的合约整理。

## 1. 噪声模型分类

按 measurement family 分三层（a12 §8.1 noise model names）：

| Layer | family | 噪声模型 | W0 spec 出处 |
|---|---|---|---|
| **Layer 1 — geometry-derived measurements** | defect_geometry / damage | 截断正态（truncated normal）+ 单调 surrogate 派生 | W0 spec 06 §3-§4 / §11.5 lognormal arithmetic_mean fix（DEBT-028 closure）|
| **Layer 2 — coverage / rate / sampling measurements** | coverage_sampling / sampling_plan | truncated normal + chain derive（DEBT-020 Round 5 sub-task 2/4）| W0 spec 06 §8 + chain_C_plus + sampling_plan_registry |
| **Layer 3 — technical validation measurements** | technical_validation / assessment | bounded gauss + integer count rounding | W0 spec 06 §9 / §10 |

**注（两个正交维度）**：本表是按 **measurement family 分 noise model 类型**的维度（维度 A — "用哪种 noise 公式"）。**具体走 Path A typical_distribution 还是 Path B named noise 双路径**由 slot 是否填了 typical 分布字段决定（维度 B — "default vs fallback"，详见 W0 spec 06 §11.5）：

- **Path A**（`recommended_distribution` 完备）= 走 typical_distribution 采样 → typical_bounds clip → physical_bounds clip → precision rounding（DEBT-026 closure 后**主路径**）
- **Path B**（typical 字段缺失 fallback）= `(physical_lo + physical_hi) / 2` 中点 + 上表 noise model（**仅 backstop**，DEBT-026 closure 前的 baseline 行为）

两个维度独立：维度 A 决定"用哪个 noise 公式"，维度 B 决定"什么时候用 noise"。同一 slot 走 Path A 时上表 noise model **不生效**（typical_distribution 自带 noise），走 Path B 时上表 noise model **生效**作 fallback noise。

## 2. Precision rounding 三档

按 a12 §8.2 + W0 spec 04 §17 `precision_steps` 字段：

| 档 | 含义 | 典型场景 |
|---|---|---|
| `coarse` | 粗采样，分辨率最低 | 业务批量检验、粗 visual inspection |
| `standard` | 标准采样 | MBIS 默认 |
| `fine` | 细采样，分辨率最高 | 精确仪器测量 / 技术验证 |

每个 `technical_measurement_registry.slot_id` 字段都带 `precision_steps={coarse: X, standard: Y, fine: Z}`（详见 W0 spec 04 §17 + 03 §4.2）。

## 3. Variance / Offset / Clip 三件

按 a12 §8.3：

| 件 | 含义 | 实现 |
|---|---|---|
| **Variance** | `abs_sigma` 绝对噪声幅度 / `rel_sigma` 相对噪声幅度 | W0 spec 06 §14 + spec 04 §17 `recommended_sigma` 字段 |
| **Offset** | 偏移（如 noise mean ≠ 0 偏向）| 一般 0，特殊场景按 spec 公式 |
| **Clip** | 采样输出 clip 到合理区间 | `physical_bounds`（硬上下界 hard clip）+ `typical_bounds`（5%/95% 实操区间 soft clip）|

`physical_bounds` vs `typical_bounds` 拆分由 DEBT-026 closure 2026-05-10 落地（W0 spec 04 §17）。

## 4. Lognormal `recommended_mean` 语义

按 DEBT-028 closure 2026-05-11：

| `mean_semantics` 字段值 | 公式 |
|---|---|
| `arithmetic_mean`（chain derive / pro round 设计标准）| `mu = ln(arith) - σ²/2` |
| `median` 或缺省（向后兼容老 slot）| `mu = ln(median)` |
| 非法值（typo 防御）| ValueError raise |

详见 W0 spec 04 §17 字段定义 + spec 06 §11.5。

## 5. distribution_source 字段约定（DEBT-020 / DEBT-021 trace）

每个走 typical distribution 采样的 slot 必须在 `distribution_source` 字段标注来源，按 W0 spec 01 §1.1.1 4 层校准：

| 允许形态 | 例 |
|---|---|
| `engineering_judgment_xxx` | 工程经验直接给 |
| `proagent_engineering_estimate_current_authority_round5_2026_05_10

该 token 是当前封口 spec 的权威估值来源，不表示等待外部专家确认。后续如果有实测再校准，必须产生新版本 token，不回改本 token 语义。` | 当前封口 spec 的权威估值来源；后续实测再校准时以新版本 token 显式覆盖 |
| `engineering_basis_xxx; threshold_alignment_note = 法规阈值落在分布 ~85 percentile，对齐良好` | 双向锚点对齐显式声明 |

**不允许形态**：

- `source = derived_from_rule_card_threshold`（rule-blind 红线）
- `source = threshold ± epsilon`（即便注释为 noise；4 层校准 Layer 4 红线）

## 6. Sidecar 噪声

sidecar measurement（duration / interval 等）使用同一套 W0 spec 06 §13/§14 噪声模型 + spec 04 §17 字段，**只是 carrier_domain 不同**（procedure / supervision / inspection_execution 而非 technical_measurement）。

sidecar bool / categorical 不使用噪声采样，按 `prevalence`（marginal）+ `conditional_formula`（按 W0 物理 state condition）双路径采样（spec 09 §1.2 + spec 06 §11.6 / §12）。
