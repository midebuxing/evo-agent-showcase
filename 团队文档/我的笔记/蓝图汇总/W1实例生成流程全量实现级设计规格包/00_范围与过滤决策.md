# W1 范围与过滤决策

## 1. 本包覆盖范围

W1 是 `WorldGenerator` **实例生成流程层**，覆盖跨层链 Step 1-5（详见 `03_九段函数总览.md` §1）：

- Step 1 build world core
- Step 2 structural / external condition
- Step 3 drainage fault
- Step 4 UBW alteration
- Step 5 fire-safety deficiency
- Step 6 coverage / sampling measurement
- Step 7 technical validation measurement
- Step 8 structural assessment measurement
- Step 9 derive risk / repair / verification / assessment flags
- sidecar 派生层（与九段并行运行，按 W0 spec 09 §1.2 双路径）

## 2. 本包**不**覆盖

| 内容 | 归属 |

| Step 0 加载 registry / formula / surrogate / constraint / sidecar contract | W0 静态资源层（W0 spec 02-09）|
| Step 10 NormativeProjection 编译 | W2 法规映射层封口版|
| HiddenGold / ObservationState / QueryEpisode / AdjudicationState | 用户原则砍除（spec 09 §1.2 + `09_用户原则说明.md` L20-L25）|

## 4. 跟 W0 spec 的边界

W1 spec 与 W0 spec 关系详见 `_拆分说明.md` §5。本包遵守 §0 source 优先级（见 `01_设计原则与本体边界.md` §0）：**W0 spec 优先；W1 cross-ref 不重复**。

## 5. 跟 法规映射层 spec 的边界

W2 法规映射层已作为独立封口包存在。W1 与 W2 的关系是：W1 产出具体世界与 sidecar 事实；W2 只读消费这些输出并生成法规映射 reference truth。W1 不因为 W2 的 family / threshold / coverage 目标改变自身生成逻辑。
