# W1 术语表与名词解释

## 1. 跟 W0 spec 00 的关系

W1 术语**继承** `W0新版全量实现级设计规格包/00_术语表与名词解释.md`（详见该文件）。本表只补 W1 阶段独有 + 新增的术语。

## 1.1 slot 术语约定（spec-wide）

按记忆 `feedback_slot_terminology.md`：本 W1 spec 包中 `slot` 默认指 **W0 端 registry slot**（W0 `registry.py` 定 5 类：technical_measurement / sidecar_measurement / sidecar_bool / sampling_plan / mechanism_condition slot）。

rule_card 端的 `semantic_slot` + `measure_registry` 2 类只在 法规映射层用，本包不涉及。**spec 内出现 `slot` 字样默认按 W0 端读**，如需指 rule_card 端会显式标"rule_card semantic_slot"。

## 2. W1 独有术语（按 a8 因果链 + 实施层）

### 2.1 五层因果模型术语（详见 `01_设计原则与本体边界.md` §2）

| 术语 | 含义 | 在 W1 哪一段实例化 |
|---|---|---|
| `FragmentContext` | 五层因果模型起点；建筑片段上下文（构件 / 材料 / 位置 / 暴露 / 结构属性 / 构造代理量）| Step 1 |
| `DriverState` | 隐含驱动层；7 类 latent factors（z_load / z_restraint / z_durability / z_age / z_workmanship / z_maintenance / z_event）| Step 1 |
| `MechanismState` | 损伤机理层；defect 的父节点（m_load_crack / m_restraint_crack / m_corrosion / m_delam_spall / m_local_event 等）| Step 2-5 |
| `ConditionState` (含 DamageState) | 缺陷几何 / 拓扑层；裂缝几何 / 剥落斑块 / 保护层损失 / 外露钢筋等 | Step 2-5 |
| `MeasurementRecord` | 测量值层；ConditionState / DamageState 的下游派生 | Step 6-8 |

### 2.2 五件物理一致性保障术语（详见 `01_设计原则与本体边界.md` §3）

| 术语 | 含义 |
|---|---|
| 分层因果采样 | "上下文 → 驱动 → 机理 → 损伤 → 测量"硬骨架；非独立 slot 拼接 |
| 机理 surrogate 库 | 低阶可解释可校准的机理派生函数；非 FEA / BIM 高保真 |
| Hard constraints | 不可能组合 / 几何上限 / 因果顺序 / component-material 兼容 |
| Soft priors | 常见共现 / 分布相关性 / 不同 fragment 经验频率 |
| 局部修复 + 拒收 | P0/P1/P2/P3 优先级体系（详见 `07_约束与四级修复.md`）|
| Coverage-controlled rejection | batch 生成时 over-sample near-threshold / neighbor-family overlap；**仅采样层控制**不是世界生成逻辑 |

### 2.3 数据流术语

| 术语 | 含义 |
|---|---|
| `WorldBundle` | W1 worldgen core 输出容器；含 13 类 world object（详见 W0 spec 04 §1.1）|
| `SidecarRuntimeBundle` | W1 sidecar 派生层输出容器；含 procedure / supervision / artifact / qual 等 B 类合规事实 |
| chain derive | A 类 measurement 通过 fragment + driver + mechanism + condition 因果链派生（不是 distribution 直接采样）|
| typical distribution | A 类 measurement 的可选采样路径（recommended_distribution + recommended_mean + recommended_sigma + typical_bounds + distribution_source），用于无 chain 公式的 A 类 slot |
| sidecar 双路径派生 | spec 09 §1.2 修订 2026-05-09：sidecar bool / categorical 走 prevalence sampling（spec 06 §12）+ conditional formula（spec 06 §11.6）双路径；sidecar measurement 走 typical distribution |

### 2.4 审计 / red-line 术语

| 术语 | 含义 |
|---|---|
| Schema firewall | W1 输出对象 schema 不含 rule_family_id / threshold / gold / observation 字段（详见 `01_设计原则与本体边界.md` §6）|
| Counterfactual test | 同 fragment + 不同 rule_card profile → W1 输出 byte-identical |
| Profile-switching audit | DEBT-020 Audit2 落地的 counterfactual 变种；profile_x070 / profile_x150 跟 baseline 输出对比 |
| Leakage audit on surface | W1 输出表层无法反推 rule_card threshold value（W0 spec 01 §1.1.1 Layer 2 + DEBT-030 待落 audit）|
