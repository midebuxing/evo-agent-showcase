## 1. W1 跨层位置（粗粒度 Step 0-7）


## 4. 函数级 P0-P3 速查

P0-P3 优先级体系详见 `07_约束与四级修复.md` §1（W0 spec 07 §1 迁出）；本表仅列**每段函数典型触发**：

| 函数 | P0 reject 典型触发 | P1 repair 典型触发 |
|---|---|---|
| Step 1 build | graph cycle / component-material 不兼容 | clamp geometry proxy |
| Step 2 structural condition | spall on non-RC / extent overflow | clamp extent / depth |
| Step 3 drainage | non-drainage component / public_health_risk_index 与 causes 矛盾 | clamp risk `[0,1]` |
| Step 4 UBW | component 不能承载 alteration | clamp structural impact |
| Step 5 fire-safety | non-fire-safety component / deficiency_present=false 但 class non-null | clamp severity |
| Step 6 coverage | negative area / ratio outside `[0,1]` | clamp ratio + count nonnegative |
| Step 7 technical validation | repair_state missing / negative test count | round count + clamp strength |
| Step 8 assessment | non-structural component / missing geometry proxy | clamp fsp `[0,2]` |
| Step 9 derive flags | derived flag references missing target / contradictory flags | recompute after measurement repair |

P3 fallback（projection 层 unknown / not_applicable）只在 法规映射层 Step 10 触发，**不属 W1 阶段**。

## 5. Sidecar 派生层与九段函数的关系

按 W0 spec 09 §1.2 双路径派生（2026-05-09 修订），sidecar 派生层**跟九段函数并行运行**，不属任何单一 step：

- sidecar measurement（duration / interval 等）：在 Step 6-7 后或 Step 9 后按 fragment / building 上下文一次性派生
- sidecar bool / categorical（procedure / supervision / artifact / qual / fire_safety.upgrade_outstanding）：按 W0 spec 09 §1.2 + spec 06 §12 sampler + spec 06 §11.6 conditional formula evaluator 一次性派生

具体派生时机由实施层决定（spec 不规定）。**逻辑边界**：sidecar 派生**只读 W1 worldgen core 的物理 state**，**不读** rule_card / projection_registry（rule-blind 红线，按 W0 spec 01 §1.1）。
