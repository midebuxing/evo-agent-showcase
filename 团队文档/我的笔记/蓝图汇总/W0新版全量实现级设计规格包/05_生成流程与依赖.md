## 1. 总体派生顺序（跨层）

下面这条派生链横跨三层。新版保留 `a12` 的世界 / 测量 / 约束 / 派生 / projection 顺序作为跨层执行链，但删除 HiddenGold 编译输出。

旧 `a12` 派生顺序为：

```text
1. Generate world core objects
2. Generate condition/technical measurements
3. Validate and repair constraints
4. Derive risk / repair / verification / assessment flags
5. Run NormativeProjection
6. Compile HiddenGold as thin projection copy
```

新版改为：

```text
W0 static resource layer:
  0. Load registries / formulas / constraints / projection bindings

Instance generation flow (详见 W1 包):
  1. Generate world core objects
  2. Generate condition / drainage / UBW / fire-safety states
  3. Generate geometry / coverage / technical validation / assessment measurements
  4. Validate and repair constraints
  5. Derive risk / repair / verification / assessment flags

Regulatory mapping layer:
  6. Run NormativeProjection for a concrete WorldBundle
  7. Stop: do not compile HiddenGold
```

第 1-5 步详细规格见 W1 包 `03_九段函数总览.md`。第 0 步是 W0 资源层职责，第 6-7 步属法规映射层。

来源：`01_a12_权威旧蓝图.md`:L1828-L1837；删除依据：`09_用户原则说明.md`:L20-L25。
