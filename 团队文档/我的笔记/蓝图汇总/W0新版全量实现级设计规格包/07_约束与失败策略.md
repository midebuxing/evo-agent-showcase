## 1. 约束分类

> **W1 视角详细阐述**见 W1 spec [`07_约束与四级修复.md`](../W1实例生成流程全量实现级设计规格包/07_约束与四级修复.md) §1。本节保留作为 W0 / 法规映射层 通用的优先级体系。

`a5` 将 hard constraints 分为物理兼容约束与规范兼容约束：物理约束包括无裂缝不应有 `crack_width_mm`、露筋只应出现在合理材料 / 构件上下文、缺陷只能挂到兼容构件；规范约束包括 exception、definition、conflict 必须落在关键 slot 上。（来源：`07_a5_权威旧蓝图.md`:L296-L310）

`a12` 将可执行失败策略冻结为 P0-P3 四级。（来源：`01_a12_权威旧蓝图.md`:L1578-L1587）

| 优先级 | 含义                                                 | 输出形态                                                              |
| ------ | ---------------------------------------------------- | --------------------------------------------------------------------- |
| P0     | `reject_or_resample`                               | reject / resample / reject projection                                 |
| P1     | `repair_world_truth_geometry_or_state`             | clamp geometry / recompute flags / repair true state                  |
| P2     | `repair_measurement_rounding_or_bounds`            | clamp ratio / round count / repair reported measurement               |
| P3     | `projection_fallback_to_unknown_or_not_applicable` | clear rule ids / resolve conflict / fallback unknown / not_applicable |

来源：`01_a12_权威旧蓝图.md`:L1580-L1587；`08_W0全量实现级设计文档_当前新版整理稿.md`:L108-L113。

## 5. Explicit unknown fallback（已迁出 W2 包）

unknown reason code 权威归 W2 `08_unknown策略.md`，固定 13 条。

W0 不新增第 14 条 `sidecar_derivation_failed`，也不维护 W2 unknown priority。sidecar 派生不可用时，W2 使用 `sidecar_join_status=partial|unavailable` 与 `unknown_reason_code=sidecar_only_fact_pattern` 表达.
