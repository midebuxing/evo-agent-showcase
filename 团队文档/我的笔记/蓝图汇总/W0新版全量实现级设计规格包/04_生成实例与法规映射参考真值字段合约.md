# 生成实例与法规映射参考真值字段合约

## 1. 对象清单与层级归属

严格意义上，W0 是静态资源 / registry 层，本身不等于某栋建筑实例，也不直接产出法规映射检验结果。本文件列的是“使用 W0 资源后会产生或消费的对象字段合约”，分为两类：

1. **生成实例对象**：由 WorldGenerator 使用 W0 registry / surrogate / formula / constraint 生成的 world truth、measurement truth、derived facts。
2. **法规映射参考真值对象**：由后续法规映射层读取某个具体 `WorldBundle`、measurement、derived facts、projection registry 和可选 sidecar join 后得到的 `NormativeProjection` 及其子对象。

因此，`NormativeProjection` 是 法规映射参考真值层的输出，不是 W0 静态资源层的输出终点；本文件保留它的字段合约，是因为 W0 的 `normative_projection_registry`、canonical slots 与 sidecar boundary 必须支撑这层映射。

## 17. 必须支持的 measurement slot contracts

**命名约定**（C-I 决策延伸；T-01 落字）：本节的 `slot_id` 主名优先采用 a4 canonical dot-notation；a12 underscore 实现侧名作为 legacy alias，登记在各 measurement 类 registry entry 的 `aliases` 字段（详见 `08_normative_projection与canonical_slots.md` §1）。

例外：纯 worldgen 几何 slot（如 `crack_width_mm / spall_area_m2`）在 a4 canonical 中没有对应 dot-notation 主名，保留 underscore 形态。

**范围列语义**（DEBT-026 拆分 2026-05-10 + DEBT-028 fix 2026-05-11）：本表 `physical_bounds` 列 = 物理硬上下界，`_sample_value_for_slot` 用作 hard clip 边界。**typical 工程现实分布参数**（`recommended_distribution` / `recommended_mean` / `recommended_sigma` / `typical_bounds` / `distribution_source` / **`mean_semantics`** 6 个字段）授权见 `03_registry_schema_matrix.md` §4.2，采样语义见 `06_surrogate公式噪声与unknown策略.md` §11.5（B 类双层 clip 规则：先按 typical 分布采样 → clip 到 typical_bounds → 再 clip 到 physical_bounds）。**`mean_semantics`**（DEBT-028 fix 2026-05-11 新加，仅 lognormal 用）：`"arithmetic_mean"` → `mu = ln(arith) - σ²/2`（pro round 设计标准语义，绝大多数 W0 lognormal slot 用此）；`"median"` 或缺省（向后兼容）→ `mu = ln(median)` 老行为。lognormal slot 必须显式标 `mean_semantics` 避免 footgun（generic distribution path 跟 chain derive path 双语义陷阱）。**A 类 slot**（`ratio.fsp.structural_performance` / `count.core_sample.minimum` / `rate.core_sample.per_concrete_volume` / `public_health_risk_index` / `index.drainage.blockage` / `index.drainage.leakage` / `flag.drainage.misconnection_present` / `rebar_exposed_length_m` / `spall_area_m2` / `crack_width_mm` / `crack_length_m` / `rate.pull_test.per_25m2` / `ratio.covered_area.inspected` / `effective_pull_test_count_per_fragment` / `inspected_area_m2` 等）走 spec 06 公式 derive，typical 分布字段不填（null）。

## 18. `NormativeProjection`（字段权威已迁出 W2）

W0 不再维护 `NormativeProjection` 字段表。

当前权威源：W2 `09_输出契约_NormativeProjection.md`。

迁出理由：`NormativeProjection` 是 W2 法规映射层输出对象，字段语义依赖 16 family、rule_card v2 消费契约、threshold regime、unknown strategy、basis_items 与 coverage status。W0 只保留实例事实字段，不维护法规映射输出字段。

W0 侧唯一允许保留的 cross-ref：

- `NormativeProjection` 引用 W1 `world_id` / `fragment_id` / component / measurement IDs。
- `NormativeProjection` 不反写 W0 / W1 输出。
- `NormativeProjection.expected_verdict` 是 W2 reference truth，不是人类最终决定。
