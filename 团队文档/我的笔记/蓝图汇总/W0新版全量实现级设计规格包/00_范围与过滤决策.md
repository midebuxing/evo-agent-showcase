## 3. 混合对象拆分原则

### 3.1 总原则

对混合对象，不一刀切删除；只保留 W0 / projection / sidecar 必需语义，删除 observation / episode / gold / adjudication 语义。（来源：`09_用户原则说明.md`:L16-L25）

### 3.2 拆分规则

| 混合来源                     | 保留语义                                                                                                                         | 删除语义                                                                                                                |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `LatentCase`               | building / component / defect / measurement canonical truth；normative applicability / definition / exception / threshold regime | `slot_records.epistemic_state`、`reveal_channel`、`observed_claims`、`source_refs`、`expected_profile.gold_*` |
| `NormativeProjection`      | family applicability、rule / trigger binding、slot roles、threshold regime、basis_items、expected_verdict、unknown_reason_code   | 不再输出 `HiddenGold`thin copy；不存 query、source、budget、runtime decisions                                         |
| `MeasurementRecord`        | target_ref、measurement_family、slot_id、value、unit、precision、method、sample_count、confidence、derivation_refs               | 不承载 observed_claims / evidence source topology / user-visible claim                                                  |
| sidecar                      | ownership、join keys、projection consumable；sidecar bundle 由 worldgen 自家派生层生成（spec 09 §1.2）；派生失败 fallback 为 `unknown` / `not_applicable`     | 不生成 artifact truth、procedure truth、supervision workflow，也不模拟 investigator；不接收外部 admin record / SidecarInput 注入             |
| unknown / not_applicable / conflict | `unknown` / `not_applicable` 作为 projection / sidecar 派生 fallback 保留；`conflict` 用于 sidecar 与 worldgen core 冲突时（生成 bug 标记）             | 不生成 ObservationState 的 `missing` / `conflict` 暴露计划或 observed_claims；废止 `sidecar_missing` 标记                                   |

## 4. HiddenGold 的具体处理

旧稿中 `HiddenGold` 是：

* `source_projection_id`
* `expected_family`
* `expected_rule_ids`
* `required_slots`
* `expected_verdict`
* `expected_report_basis`
* `projection_status`
* `unknown_reason_code`

并且这些字段都由 projection 复制而来。（来源：`01_a12_权威旧蓝图.md`:L541-L566、L1880-L1888）

新版处理：

1. 不生成 `HiddenGold` 对象。
2. 不在 batch manifest、QA 断言、sidecar contract 中引用 `HiddenGold`。
3. `NormativeProjection.basis_items` 是正式法规投影结果，不再复制到任何 gold 对象。
4. 旧函数 `compile_normative_projection_and_hidden_gold` 只可保留其 projection 编译语义；HiddenGold thin-copy 半段必须删除。（来源：`01_a12_权威旧蓝图.md`:L1490-L1527；`09_用户原则说明.md`:L20-L25）

## 5. Observation / Evidence / Episode / Adjudication 的具体处理

| 内容                  | 新版状态                                                                                  |
| --------------------- | ----------------------------------------------------------------------------------------- |
| Evidence Topology     | 删除；不作为 W0 输出、registry、sidecar、projection 输入                                  |
| Observation Plan      | 删除；不生成 initial_visible / fact_kg_recoverable / user_recoverable / never_recoverable |
| `ObservationState`  | 删除；不生成 source_graph / slot_records / visibility_sets                                |
| `QueryEpisode`      | 删除；不生成 query_text / budget / allowlists                                             |
| `AdjudicationState` | 删除；不生成 fullinfo_truth / partialinfo_gold                                            |
| `GoldLabeler`       | 删除；不定义 gold_route_action / acceptable_next_question_bundle_ids                      |
| runtime trace         | 删除；不作为 batch QA 或学习闭环产物                                                      |

旧稿将这些内容作为完整生成闭环 Step 4–Step 8；新版不继承这些步骤。（来源：`04_a9_权威旧蓝图.md`:L465-L600；`09_用户原则说明.md`:L5-L8）
