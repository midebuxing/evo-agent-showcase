> 跨包权威源与负向不变量见：`../_封口总则_字段权威源与负向不变量.md`。如本章与总则冲突，以总则和字段所属包权威章节为准。


W2 法规映射层依赖图。本章列三层依赖：**(a) 跨层依赖图**——W0 静态资源层 / W1 实例生成流程层 / rule_card v2 数据系统 → W2 → 下游消费方（evo-agent 训练层 / parquet 输出 / batch 聚合）；**(b) W2 内部函数依赖图**——4 个主入口 + 6 个公开 helper + 18 个内部 helper 跨 phase 1-4 的调用链；**(c) W2 ↔ 上下游接口图**——W2 ↔ W0 / W2 ↔ W1 / W2 ↔ rule_card v2 / W2 ↔ evo-agent 4 边界的资源 / 事实 / 元数据 / 参考真值流向；**(d) 段内数据流**——选 2-3 典型 fragment-level projection 数据流。

- 4 个主入口 + 6 个公开 helper + 18 内部 helper 分类详见 `03_projection_executor函数总览.md` §2；本章只画依赖图不重复实施细节

- W0 / W1 / rule_card v2 输入合约详见 `02_输入合约与W0_W1依赖.md`；本章只画资源流向

### 4.1 数据流示例 A — external_components 检验 family（数值阈值通路）

某 fragment 含外构件结构表面 crack mechanism + measurement `length.crack.width = 0.3 mm`，family routing 走 `mbis.inspection.external_components`，threshold 评估通路：

```text
[Input]
   fragment.component_type_id = "external_wall_section"
   mechanism.mechanism_family = "structural_crack"
   condition.severity_index = 0.5
   measurement.slot_id = "length.crack.width"

   │       ├── 检查 _COMPONENT_TYPE_FAMILY_OVERRIDES
   │       │   ("external_wall_section" 不在 override 列表)
   │       └── fallback MECHANISM_FAMILY_TO_PROJECTION_FAMILIES["structural_crack"]

        }]
        │
        ▼
[Step 2 — family 路由 / conflict 解析]

                           conflict_group_id="structural_external_surface")
   │
   ├── candidate 长度 1 → 直接返回 ([family], None)
   │
   └──► selected_family_ids = ["mbis.inspection.external_components"]
        conflict_reason = None
        │
        ▼
[Step 3 — threshold 评估]

   │

   │
   ├──► H5 build_threshold_evaluation(rule_id="MBIS-EXT-CRACK-WIDTH-V1",

                       pass_bool=False)
```

### 4.4 数据流共性总结

3 个数据流示例的共性：

| 阶段 | 调用入口 | 关键决策点 |
|---|---|---|
| applicability 评估 | Cat C `_build_candidate_families_for_fragment` | mechanism_family + component_type → candidate family list（当前 simplified routing 绕开 applicability_predicates evaluator） |
| family 路由 | H3 `resolve_family_conflict` | 4 个 conflict_group selector 之一处理多 candidate 竞争 |
| threshold 评估 | H5 `build_threshold_evaluation` | width 公式 family 表 hit → unit fallback → 兜底 0；regime 分箱 + operator 求值两套独立维度 |
| basis 构造 | 5 kind 派生 | 每 ThresholdEval 一项 `threshold_compare` basis；unknown 走 `family_uncovered`；bool slot 走 `bool_assertion`；worldgen core fact 走 `world_origin`；measurement 走 `measurement_origin` |
| 输出 | NormativeProjection 构造 | C023 / C024 / C025 输出契约红线 gate 检查 |

详细约束 + 失败路径见 `07_threshold_regime与冲突回退.md` + `08_unknown策略.md` + `09_输出契约_NormativeProjection.md`。
