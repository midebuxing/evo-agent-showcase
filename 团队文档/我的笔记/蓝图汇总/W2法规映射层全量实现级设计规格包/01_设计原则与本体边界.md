## 1. W2 的定位

W2 是 `WorldGenerator` 三层链中的**法规映射层**，位于 W0 静态资源层之后、W1 实例生成流程层之后；W2 在 W1 输出 `WorldBundle` + `SidecarRuntimeBundle` 完成后开始运行。

W2 职责：

1. 消费 W1 输出 `WorldBundle` + `SidecarRuntimeBundle`；
2. 消费 W0 资源 `normative_projection_registry` + canonical_slot universe + sidecar_ownership_registry + sidecar_measurement_registry；
3. 消费 rule_card v2 bundle（`compile_projection_contract` / `compile_projection_specs` 编译 → projection contract / compiled spec；`regulation_thresholds.py::load_all_thresholds` 加载真阈值数据）；
4. 按 fragment 评估 projection family applicability + family 冲突回退 + threshold 评估 + basis 构造 + unknown / not_applicable fallback；
5. 产出 `NormativeProjection` 参考真值（含 `ProjectionFamilyEval` / `ThresholdEval` / `ReportBasisItem`）；
6. batch 级聚合 + 输出 Summary / Results / Samples 三件套；
7. 在 batch 生成时按 5-bin regime / neighbor-family overlap / recoverable missing 做 coverage-controlled rejection（采样侧）。

W2 不做：

- W0 静态资源 / schema / surrogate / formula / constraint 定义本身（属 W0）；
- W1 九段函数 / sidecar 派生层执行 / `WorldBundle` 字段合约定义本身（属 W1）；
- rule_card v2 数据规格定义（属 rule_card v2 系统，本包仅描述消费契约）；
- HiddenGold / ObservationState / QueryEpisode / AdjudicationState / GoldLabeler / 巡检员模拟（已删，详见 00_范围与过滤决策.md §3）；
- evo-agent 训练逻辑（属 evo-agent 独立层，不属于本封口包）；
- 反向写回 W1 输出（W1 → W2 严格单向，详见 §4）。

## 2. 主设计原则：a9 投影器降级

W2 的**核心设计原则**继承 a9 §1 一句总判断：

> **保留对象层，但把法规从"世界生成器"降级为"投影器 + 分桶器 + 裁决依据"；世界真值由独立的 fragment world model 生成。**

新版进一步剪裁（按用户原则 09.md + 2026-05-13 D-2 决策）：

| a9 §2.2 法规三角色 | 新版处置（W2 端） |
|---|---|
| **projection** | **保留作 W2 主体职责**——把 `WorldState` 投影成 family applicability / trigger / rule_card / obligation / threshold / definition / exception 结构 / slot roles / threshold regime（详见 §2.1）|
| **coverage control** | **保留作 W2 采样侧职责**（用户 D-1 决策 2026-05-13）——batch 生成时按 5-bin regime / neighbor-family overlap / recoverable missing 过采（详见 W2 spec 11，本包内）；observation mask coverage 部分**砍除**（按用户原则） |
| **adjudication source** | **角色废止**（用户 D-2 决策 2026-05-13）——HiddenGold + GoldLabeler + RuntimeVerifier 巡检员模拟链全砍后，"adjudication source"语义被 projection 角色自身吸收（rule_card v2 作 immutable rule snapshot 给 projection 提供 family / threshold / basis 信息，这就是 projection 角色本身，不再单独列）|

### 2.1 a9 §2.3 可投影 / 不可投影边界

**法规可投影出来的**（W2 主体职责）：

- family applicability
- trigger set
- rule_card set
- obligation / threshold / definition / exception 结构
- slot roles（同一个 canonical slot 在某 family 下是 route-critical，在另一 family 下是 closure-critical）
- threshold regime（`far_below` / `near_below` / `exact_threshold` / `near_above` / `far_above`）
- full-info symbolic outcome（W2 端体现为 `ProjectionFamilyEval.verdict` + `NormativeProjection.basis_items`）
- neighbor-family relations

**法规绝不能直接生成的**（W1 / W0 / 砍除项地盘）：

- 建筑 / 构件 / 缺陷 / 测量的 canonical truth（属 W1 worldgen core）
- 缺陷严重度与测量值本身（属 W1 mechanism / measurement surrogate）
- ~~source availability~~ / ~~missing / unknown_world / conflict 的证据状态~~ / ~~query text~~ / ~~follow-up 轨迹~~ / ~~runtime trace~~ / ~~gold action 本身~~（observation / episode / gold 链全砍）

一句话：**法规定义"如何解释世界"，不定义"世界本身是什么"。**

### 2.2 W2 端时序声明

按 a12 §14.4 + 用户 2026-05-13 决策：

- W2 当前阶段**不建事件链 / 不建时序引擎**
- projection 评估是 per-fragment snapshot：W1 输出 `WorldBundle` 完成后 W2 一次性消费，无 time-step 演进
- 当前 W2 实施只停留在 single-card / single-fragment 评估，**未消费** rule_card v2 的 `obligation_graph`（rule_card 端字段，描述义务图节点 / 边）；此为长期 trace（如需 obligation chain 评估属未来 W2+ extension，不在本包范围）

## 3. W2 端边界（合法消费法规 + W2 自身红线）

按 memory `feedback_rule_blind_only_w0_w1.md`：**rule-blind 红线只属 W0/W1 worldgen 层**（W1 worldgen 不读 rule_card 反推世界生成参数；详见 W0 规格 01 §1.1 + W1 规格 01 §5 + §6）——rule-blind 红线**不延伸**到 W2 端，不存在"在 W2 端的表现"或"消费方版本"。

W2 法规映射层是**法规消费层**——**合法消费**法规（rule_card v2 + `normative_projection_registry` + projection_runtime_mapping）是 W2 本职工作。但 W2 端有**自身红线**约束 evaluator 行为（详见本包 `10_禁止依赖.md` §2 W2 红线 10 条），跟 rule-blind 红线**正交不冲突**：

| 红线 | 适用层 | 方向 | 具体禁止 |
|---|---|---|---|
| **rule-blind 红线** | W0/W1 worldgen 层 | W1 ← rule | W1 worldgen 不读 rule_card 反推世界（防 evo-agent 训练数据泄漏）|
| **W2 红线 1**（不反向写回 W1）| W2 法规映射层 | W2 → W1 | W2 评估时不修改 W1 输出（`WorldBundle` / `SidecarRuntimeBundle`）|
| **W2 红线 6 / 8**（evo-agent-blind 镜像）| W2 法规映射层 | W2 → evo-agent + W2 → W1 内部派生过程 | W2 不消费 evo-agent 训练数据；W2 不消费 W1 内部分布参数 / surrogate 公式 |

详细 W2 红线清单见本包 `10_禁止依赖.md` §2。

### 3.1 W2 端可读 / 必须读的资源

| 资源 | W2 端权限 | 来源 |

| `sidecar_measurement_registry`（sidecar 数值 slot 注册表）| **必读** —— sidecar 数值 slot 的 unit / measurement_family 查（projection executor 从 sidecar bundle 抽 numeric value 时按 W0 规格 04 §1.4 + W0 规格 09 §1.2 用 `sidecar_measurement_registry` 翻 unit / family）| W0 规格 09 / 11 §7.2 |
| `sidecar_ownership_registry`（sidecar slot ownership map）| **可读不强制** —— sidecar slot ownership map 主要在 W1 sidecar 派生层使用；W2 端通过已派生 `SidecarRuntimeBundle.{procedure_gate_state, artifact_requirement_state, supervision_runtime_state, completion_runtime_state, facts}` 5 桶分流间接消费 ownership 信息 | W0 规格 09 §1.2 + W0 规格 11 §7.1 |

### 3.2 W2 端禁止写回 W1 输出

W2 是**只读消费方**，绝不能反向写回 W1 输出：

- W2 不修改 `WorldBundle` 字段内容
- W2 不修改 `SidecarRuntimeBundle` 字段内容
- W2 不调用 W1 worldgen surrogate / sidecar 派生函数
- W2 不写 W0 registry / formula / constraint

如 W2 评估发现 W1 输出存在异常（如 measurement 越界），按 W2 端 fallback 路径输出 `unknown` + 对应 `unknown_reason_code`（详见 W2 规格 08），**不修复 W1 输出**。

### 3.3 evo-agent-blind 边界

按 W0 规格 01 §1.1.1 Layer 2 + W1 规格 01 §8：

- evo-agent 看到的是 W2 已采样具体输出（`NormativeProjection` 字段值），**不可反推**出"这个 projection 是按哪条 threshold 派生的"或"这个 family 选择是按什么 priority"
- W2 端 `normative_projection_registry` 配置参数 / `conflict_group` 派生公式 / `unknown_reason_code` priority 路由 / threshold_regime width 公式都留在 W2 内部，**不外泄给 evo-agent**
- evo-agent 训练阶段消费 `NormativeProjection` 作为参考真值；evo-agent 不能调 W2 内部 projection_registry 参数 / 不能调 rule_card v2 数据

## Reference truth 与最终决定边界

W2 输出的是法规映射 reference truth，用于训练、评测、报告依据追溯与 Closure Verifier 前置检查。W2 不输出人类巡检最终决定。

禁止字段 / 语义：

- `final_decision`
- `human_decision`
- `inspector_verdict`
- 任何把 AI 输出包装成人类巡检员最终决定的字段

`expected_verdict` 只能表示 W2 在当前 rule_card / projection binding / world facts 下的参考判定。后续副驾驶链路必须经过 Closure Verifier 与人类确认边界，不得由 W2 直接替代.

## 4. 三层接口边界（W2 端定位）

W2 端的具体接口边界：

| 边界 | 方向 | 内容 |
|---|---|---|
| W0 → W2 | 单向消费 | W2 消费 W0 资源（registry / canonical_slot / sidecar contract / parquet schema）；W2 不修改 W0 资源；W2 不绕过 W0 直接定义新 slot / 新 schema |
| W1 → W2 | 单向消费 | W2 消费 W1 输出 `WorldBundle` + `SidecarRuntimeBundle`；W2 不写回 W1 输出 |
| rule_card v2 → W2 | 单向消费 | W2 通过 `compile_projection_contract` / `compile_projection_specs` 编译 rule_card bundle；通过 `regulation_thresholds.py` 加载真阈值；W2 不修改 rule_card 数据 |
| W2 → evo-agent | 单向输出 | W2 输出 `NormativeProjection` 是 evo-agent 训练 / 评估的参考真值输入之一；evo-agent 不可调 W2 内部 projection_registry / threshold value 参数 |
| W2 → W1（**禁止**）| 红线 | W1 输出 schema 不含 `rule_family_id` / `trigger_id` / `threshold_regime value` / `gold_route` 等 W2 端字段（W1 规格 01 §4 Schema firewall）；W2 不向 W1 反写 |

projection-only rule use 原则（a9 §5.2 剔除 observation / gold 后保留）：rule_card / `normative_projection_registry` **只在 W2 中使用**，绝不在 W1 worldgen 路径中读取；W1 worldgen 构建时不注入 rule snapshot。这条红线在 W1 端由 W1 规格 01 §5 + §6 维护，在 W2 端则被 §3.1 允许 W2 读 rule_card 的"合法权限"反向印证。

**DEBT-030 §A 组耦合点（forward-direction trace）**：

W2 的字段合约权威归本包章节；实现物理位置或代码迁移状态不属于本章正文。
