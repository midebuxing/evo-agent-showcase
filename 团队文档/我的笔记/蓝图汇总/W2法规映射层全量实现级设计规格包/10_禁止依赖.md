# W2 禁止依赖

> 跨包权威源与负向不变量见：`../_封口总则_字段权威源与负向不变量.md`。如本章与总则冲突，以总则和字段所属包权威章节为准。

## 1. 一句话红线

W2 可以合法消费 W0 / W1 / rule_card v2 来生成法规映射 reference truth，但不得反写 W0 / W1，不得伪造世界事实，不得复写 rule_card v2 数据规格，不得向 evo-agent 暴露 evaluator 内部配置。

## 3. 字段黑名单

以下字段 / 对象不得作为 W2 输出字段进入封口版数据生成层：

- `HiddenGold`
- `AdjudicationState`
- `ObservationState`
- `QueryEpisode`
- `GoldLabeler`
- `sidecar_derivation_failed`（已撤回 / 禁止）
- `pending` verdict（当前输出禁用）
- `final_decision`
- `human_decision`
- `inspector_verdict`

## 4. dependency boundary

| 类别 | 边界 |
|---|---|
| 允许读取 | W0 registry / schema / measurement / sidecar contract；W1 已生成的具体 `WorldBundle` / `SidecarRuntimeBundle`；rule_card v2 manifest + 13 sub-file + `projection_runtime_mapping_v1.json` |
| 禁止读取 | W1 内部 distribution / surrogate / seed / retry 状态；evo-agent 训练状态；rule_card v2 以外的未授权人工判定链 |
| 禁止写入 | W0 registry；W1 输出；rule_card v2 数据文件；evo-agent 训练特征 |

## 5. 双向锚点对齐 vs 反推作弊的边界

W2 的 family / threshold / rule_card 消费只发生在法规映射层。它不得反向成为 W1 worldgen 的采样条件，也不得作为 evo-agent 可见的内部 evaluator 配置。

## 6. 不允许 silent 修复 + silent fallback

- W2 不 silently 修改 world facts。
- W2 不 silently 补 sidecar facts。
- W2 不 silently 将多 family conflict 改写为单 family pass。
- W2 不输出 `pending` 作为当前数据生成层状态。
- W2 不输出 `sidecar_derivation_failed`。

### 6.3 一致性约束（封口版）

- 当 `sidecar_join_status=available` 时，不得因 sidecar join 缺失触发 `unknown_reason_code=sidecar_only_fact_pattern`。
- 当 sidecar 所需接口部分缺失时，`sidecar_join_status=partial`；若导致 unknown，可用 `unknown_reason_code=sidecar_only_fact_pattern`。
- 当 sidecar 所需接口不可用时，`sidecar_join_status=unavailable`；若导致 unknown，可用 `unknown_reason_code=sidecar_only_fact_pattern`。
- 不存在 `sidecar_join_status=sidecar_derivation_failed`。
- 不存在 `unknown_reason_code=sidecar_derivation_failed`。
