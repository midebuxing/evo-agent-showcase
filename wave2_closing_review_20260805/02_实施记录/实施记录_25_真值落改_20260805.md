## 步骤 2：schema 扩三态 ＋ 评分器判据改造（决议 §三.2）

### 2.1 schema 编码：`boolean ∪ const "unknown_pending"`（不是三值字符串枚举）

`applicable_normative_item_truth_v1.schema.json:54-57`：
`{"type":"boolean"}` → `{"oneOf":[{"type":"boolean"},{"const":"unknown_pending"}]}`。

**为什么不是「统一改成三值字符串枚举」**（决议把编码留给实施按 schema 现形定）：
底稿 A3 要求白名单外 **2,741 行逐字节相同**。改成字符串枚举意味着全部 2,770 行的
`applicable` 都要从 JSON 布尔改写成字符串 ⇒ **A3 结构上不可能通过**。
⇒ 只有 `oneOf` 这一种编码与 A3 相容。既有 2,766 行保持布尔不动，只有 4 行是字符串。

description 里同时写死了消费纪律：**一律用 `is True`/`is False` 判，
Python 真值判断会把非空字符串判成适用**。
