# 实验报告 EXP-004：冷启动 LLM 价值的跨切分稳健性

- **日期**：2026-05-30（夜）
- **状态**：✓ 完成

## 由来
EXP-001/002 的冷启动结论（K=0 时 LLM 0.306 >> 统计量 0.000）建立在单组测试型上。问：换不同批没见过的楼型，K=0 LLM 世界知识价值是否一致成立、还是依赖 LLM 是否"认识"该型。

## 方法
3 组不相交的没见过楼型，每型 ~18 栋，K=0 纯世界知识 per-type 排序（强框架去审计块 + 中文释义），3 种子，vs random / statistic-no-data。脚本 `杂物箱/exp004_coldstart_robustness.py`。

## 结果

| 组 | 楼型 | llm K=0 P@1 | random | statistic | >random? |
|---|---|---|---|---|---|
| A | 港式老楼（UBW/TONG/WALKUP）| **0.352** | 0.101 | 0.000 | 是 |
| B | 机构/仓库/幕墙 | **0.148** | 0.103 | 0.000 | 是 |
| C | 混合高层/公屋/转换层 | **0.228** | 0.101 | 0.000 | 是 |

判定：① 三组 llm K=0 **全 > random** ✅ ② statistic-no-data **全组崩塌 0.000**（无数据=无信息）✅ ③ 组 A 锚点复现 0.352（±0.10 容差内）✅。

## 结论
**✅ 冷启动 LLM 世界知识优势跨切分稳健**：换不同批没见过的楼型（B/C）仍一致给出 >random 的有用先验，不只在它"认识"的港式老楼组（A）才行——EXP-001/002 的"冷启动有价值"泛化成立。

**诚实 caveat：幅度 type-dependent**——A（港式老楼→ubw，LLM 很熟）0.352 强；B（通用现代型 机构/仓库/幕墙）0.148 仅微超 random 0.103。**冷启动价值方向稳健、幅度取决于楼型鲜明度/LLM 熟悉度。**

- 锚点口径差异：本脚本组 A 用 held-out O 并集 + 每型 18 栋，与 EXP-002 的 12 栋+audit候选集不完全同口径，故 0.352 ≠ 0.306（同方法论锚点、±0.10 容差）。
