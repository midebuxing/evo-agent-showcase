# 实验报告 EXP-005：冷启动(K=0) LLM 世界知识价值的 per-type 光谱

- **日期**：2026-05-30（夜）
- **状态**：✓ 完成

## 由来
EXP-004 发现冷启动 LLM 优势幅度 type-dependent（组 A 0.352 / B 0.148）。EXP-005 做成**全楼型光谱**：每型 K=0 LLM 分诊 P@1 vs random 排序 → "哪些型 LLM 冷启动先验值得信"的实用 map。

## 方法
自动筛 13 个够格楼型（held-out ≥12 栋 + 真 fail 家族 ≥2 类；剔 COASTAL/PODIUM-DRAINAGE 单一-fail 型）。全局候选家族并集（跨型可比），每型 K=0 纯世界知识 per-type 排序（强框架+释义），3 种子。脚本 `杂物箱/exp005_pertype_spectrum.py`。

## 结论：冷启动 LLM 价值不均匀，且有可解释的系统性偏差
**真规律不是"楼型 distinctiveness"，是 LLM 先验的 salience bias**：LLM 冷启动首位几乎只押 **ubw / external_components**（它脑中的"头条"港式风险——僭建、外墙剥落）。
- **命中**（型真实模态 = ubw/external）→ 大赢（UBW-PRONE +0.46、MIXED-USE +0.34）。
- **漏**（型真实模态是平淡的 **drainage**）→ **反而比瞎猜差**（NT-VILLAGE −0.10、MASS-HOUSING −0.05，LLM 押 ubw/external、真值偏排水）。
- 即使 TONG-LAU 这种特征鲜明的型，LLM 押 ubw、真值偏 external，也只 ≈random。

**→ 冷启动 LLM 懂"头条风险"、瞎在"平淡失效模式（排水）"。** 这把 EXP-001/002 的"冷启动有价值"细化成更诚实的版本：**价值真实但不均匀，且系统性偏向 salient 风险**。实用 map：headline-risk 主导的型信 LLM 冷启动；drainage/平淡主导的型别信。
