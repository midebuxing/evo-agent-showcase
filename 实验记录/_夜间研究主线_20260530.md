## 循环协议（务必守，否则会停）
1. **始终让一个子代理在后台跑实验**。它跑完唤起我 → 我分析+记录+**立刻派下一个子代理**。**永不空手结束回合**（回合结束时必须有待跑的后台任务，否则链断、就停了）。
2. **分工（教训 2026-05-30 夜，子代理已栽 3 次）**：子代理擅长**写脚本 / 跑短确定性脚本**，**但跑长 LLM 脚本会栽**（脚本被自动转后台后，子代理以为"等通知"就结束了、不带结果）。所以 **长 LLM 脚本我自己跑**（auto-background 对我有效、跑完会带结果唤起我）；子代理只**写脚本 + 跑确定性短任务**。我做设计/分析/记录。恢复孤儿 python 跑的脚本：`Wait-Process -Id <pid> -Timeout N; Get-Content <output>`。
3. 子代理 prompt 要：① 指明读哪个现成脚本当模板（`杂物箱/mvp_*.py`）② 明确执行注意（前台跑、长任务会自动转后台→等通知读 output 文件、别自己开后台、别轮询、别重起）③ 只回报关键数字。
