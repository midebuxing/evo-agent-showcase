# 实验报告 EXP-007：活探索版闭包翻页 —— 冷启动先验能否在真 agent 里省轮

- **日期**：2026-05-30（夜→续）
- **状态**：⚠️ **结论全部作废**（detection 偷看 W2 + 任务从根上误解，2026-05-30 用户拍正）→ 正确重定见 [EXP-008](EXP-008_工具箱agent完整闭包核验_20260530.md)

> **作废原因**：① 把 `W2-fail` 当「agent 要找的违规」—— 实际 **agent 不判违规、只做完整闭包核验，W2 是「完整闭包结果」的参考真值** ② detection `det = f in fail_present` 推理时偷看 W2、违反 blind 红线 ③ 工具调用写成固定步骤（实为 agent 可选工具）。探针实证 blind 下闭包对真 fail 家族 **9/9 判 `unknown`、`violated`=0**，「翻页找违规」本就伪命题，3.94 轮只因偷喂 W2。下文保留作过程留痕。
- **模型**：sixthsense `deepseek-v4-flash-h`
- **定位**：把 EXP-001~005 的离线单轮 triage（证明强框架 LLM 冷启动先验有价值，但 LLM 只调一次、不在工具循环、无"轮数"）升级到**真·多轮活 agent**（LLM 在环自己调闭包翻页、靠中间结果决定下一步），度量从 P@1 换成**省轮** —— 补 EXP-001 方案写了、但夜里没测的那半截。这是 evo 探索版第一次真正落到「LLM 推理时多轮自适应」形态。

---

## 0. 一句话

离线台证明：强框架 LLM 冷启动先验在「一次性挑 top-1」里 P@1=0.306 >> 统计量 0.000（EXP-001 Stage4 K=0）。本实验把它装进**活 agent**：LLM 每轮看楼型（+先验）+ 已查结果，自己决定下一个查哪个 `open` 家族，直到查到真 fail。问：**冷启动世界知识先验能否让活 agent 用更少轮数查到真 fail**（没见过的楼型 + 零审计）。

## 1. 由来 / 与 triage 线的关系

- EXP-001~005 是**离线单轮评测台**：LLM 调一次排序、不在工具循环、无"轮数"。证明了信号价值（冷启动 0.306）+ 边界（salience bias，只懂头条风险）。
- 但**没证明**装进活 agent 能省轮 —— 离线台根本没有"轮数"这个量。
- 已有 paging 雏形 `杂物箱/mvp_evo_paging_llmloop.py` 跑过**同型 in-distribution**：`llm_skill` 2.25 = `fixed_stat` 2.25（训练统计先验，有数据→打平，呼应 triage）；`llm_skill` < `llm_noskill` 3.125（先验有用）。avg_K=1.0。**但它的 `skill` 是训练频率统计（有数据才有），不是世界知识冷启动先验，且 train/test 同型、统计量没数据饿。**
- 本 EXP-007 补**冷启动端**：测试型 disjoint + 强框架世界知识先验，在真 agent 测省轮。两端合起来 = 完整的「活 agent 省轮」故事：有数据（同型）`llm_skill`≈`fixed_stat`（旧 paging）；冷启动（没见过型）`llm_coldprior` 省轮 vs `fixed_stat` 数据饿（本实验）。

## 2. 任务与机制（活 agent）

- 一栋楼：`present` = 有候选卡的 ~10 个粗家族；`target` = W2-fail ∩ `present`（fail-only 投影 → ≈1 个）。
- agent 多轮：每轮从**未查**家族里选一个"查"（花一轮），环境反馈该家族真 fail 没（detection），结果入 log 喂下一轮。
- 目标：最少轮数查全 `target`。度量：平均查全轮数（下限 = 平均 K）。
- **LLM 在环** = 每轮 LLM 看楼型（+先验）+ 已查 log 自己选 next → **靠中间结果决定下一步**。

## 3. 冷启动 regime（关键，对齐夜间 EXP-001）

- **训练型**（学 `fixed_stat` 统计先验）：MIXED-USE-HIGHRISE / INDUSTRIAL-FACTORY / MASS-HOUSING-RC-WALL / INSTITUTIONAL-RC-BLOCK。
- **测试型**（没见过，评测省轮）：UBW-PRONE-OLD-BLOCK / TONG-LAU-MIXED-USE-MASONRY / LEGACY-WALKUP-RESIDENTIAL。
- 统计先验从训练型学（全局违规频率）、套到没见过的测试型 → **数据饿**（对应夜间 Stage2 测试型统计量 0.074 < 随机 0.101，系统性误排）。LLM 零审计靠世界知识。

## 4. 四方对照（度量 = 查全轮数，越低越好，下限 = K）

| 变体 | 含义 |
|---|---|
| `retrieval_rank` | 按检索秩翻（零学习下界） |
| `fixed_stat_xtype` | 训练型全局违规频率排序套测试型（跨型统计、数据饿、无 LLM = "跟大模型无关"基线） |
| `llm_noprior` | LLM 多轮翻页、中性 framing（家族带释义但无 per-type 先验引导） |
| `llm_coldprior` | LLM 多轮翻页 + **强框架世界知识冷启动先验**（语义释义 + per-type"这类楼最常违规"，K=0 无审计） |

**判定**：`llm_coldprior` 轮数 < `retrieval_rank` 且 < `fixed_stat_xtype` 且 ≤ `llm_noprior` → 冷启动世界知识先验在活 agent 里真省轮（夜间离线结论在真 agent 兑现）。

## 5. 先验怎么塞（强框架，沿用夜间 Stage 3b/3c 验证过的口径）

- 家族 coarse 短名 → 中文释义（`FAMILY_GLOSS`）；楼型中文描述（`TYPE_DESC`）。
- per-type"这类楼（结合物理/年代/使用特征）最常出现违规的家族优先"框架，逐轮选 next。
- K=0：不给审计块，纯世界知识（对应夜间 Stage4 K=0 = 0.306）。
- `llm_noprior` 与 `llm_coldprior` 唯一差异 = 有没有这个强框架引导句（隔离"强框架激发先验"这一个变量）。

## 6. 度量 + 方差

- 平均查全轮数（主），per-type 拆解。
- LLM 变体 **3 种子方差**（temp 0.3），单种子不下结论（夜间纪律）。

## 7. 诚实局限（先写在前头）

- **oracle detection 假设**：查一个家族，环境立即反馈真 fail 没（`det = f in fail_present`，借 W2 真值当**无噪检测器**）。真实活 agent 查一个家族，闭包返回 obligation 三态（92% `open`），**不直接** = W2 verdict。这是理想检测器简化，度量的是"先验排序 + 自适应搜索效率"的**上界**；后续可换带噪检测信号（`open` 深度 / 缺关键 fact 数）。
- **K≈1 局限**：fail-only 投影 → 每栋 ≈1 个 fail 家族，"查全" ≈ "查到第一个"，多轮自适应主要是排除法、戏份轻；省轮主要由**初始先验排序质量**决定。真正考验"中间结果自适应"需筛 K≥2 楼（多 fail）作补充专项。
- 受控合成数据、fail-only W2、3 种子方差。诚实负结果照实记。

## 结果页

### 全量结果（2026-05-30，✓ 完成，3 种子，n=18，UBW/TONG/LEGACY 各 6）

**主结果（平均查全轮数，越低越好，下限 K=1.0，|O|≈9.9）：**

| 变体 | 平均轮数 | 3 种子 |
|---|---|---|
| random（零信息闭式） | 5.47 | — |
| fixed_stat_xtype（跨型统计、数据饿） | 5.56 | — |
| retrieval_rank（检索秩、零学习） | 4.22 | — |
| llm_noprior | 4.61 | [4.50, 4.61, 4.72] |
| **llm_coldprior** | **3.94** | [3.94, 3.67, 4.22] |

**判定：✓ llm_coldprior 总体赢全部基线** —— < random 5.47、< fixed_stat 5.56、< noprior 4.61、< retrieval_rank 4.22。三种子 coldprior 全段 < noprior，信号稳。**夜间离线 P@1 结论在真·多轮 agent 的轮数上兑现**：强框架冷启动世界知识先验让活 agent（LLM 自己翻页、靠中间结果决定下一步）用更少轮数查到真 fail。

### 三个关键发现

1. **✓ 冷启动先验省轮**：coldprior 3.94 比随机 5.47 省 ~1.5 轮、比无先验 LLM 4.61 省 0.67 轮，三种子全稳。
2. **★ fixed_stat 5.56 > random 5.47（比随机还差）**：跨型统计量数据饿铁证 —— 训练型常见 fail（`external_structural_validation` 18 / `structural_components` 17 / `external_components` 16 / `drainage` 15）排前，测试老楼真 fail（`ubw` 5 / `fire_safety` 4）被系统性排后，比瞎翻还糟。完美复刻夜间 Stage2 崩塌（0.074 < 随机 0.101）。
3. **强框架有用**：coldprior 3.94 vs noprior 4.61，省 0.67 轮（隔离的就是「这类楼最常违规」强引导句）。

### per-type 拆解（★ 不均匀，salience bias 在活 agent 复现）

| 楼型 | cold | noprior | rank | stat | rand | LLM 押得准不准 |
|---|---|---|---|---|---|---|
| UBW-PRONE | **3.06** | 3.56 | 5.00 | 6.00 | 5.50 | 半对（3 栋 fail ubw→1 轮命中；3 栋 fail fire→押 ubw 落空 4–7 轮） |
| TONG-LAU | 4.89 | 5.33 | **3.33** | 4.00 | 5.50 | 多错（真 fail 散在 drainage/gate/ext_struct，押 ubw/external 是盲区） |
| LEGACY | **3.89** | 4.94 | 4.33 | 6.67 | 5.42 | 较对（5 栋 fail fire 但 cold 把 fire 排得比 noprior 前；1 栋 ubw→1 轮命中） |

- **UBW / LEGACY：cold 大赢**（世界知识押对 ubw、或把 fire 排前）。
- **TONG-LAU：cold 4.89 反输 retrieval_rank 3.33** —— 唐楼真 fail 分散到 `drainage`/`gate_and_proposal`/`external_structural_validation`（LLM 强押 ubw/external 的盲区），检索秩恰好排得好。

### 诚实 caveat

- **retrieval_rank 是意外强基线（4.22，仅次于 cold）**：检索-违规信号在 `external_structural_validation`/`external_components` 等家族耦合，让「检索秩」免费拿到不错排序。**cold（3.94）只比它好 0.28 轮 —— 对检索秩优势温和**（对 random/stat 才显著）。
- **per-building 看 LLM 行为**：押 `ubw` 命中 ubw 型（1 轮），押错 fire/drainage/gate 型（4–10 轮）；`gate_and_proposal` 程序性家族 LLM 几乎不押（唐楼某栋 cold 9.3 轮）。
- oracle detection（查一家族即知真 fail 没）+ K≈1（每栋 ~1 个 fail），见方案 §7：度量的是「先验排序质量」上界，真实带噪检测会打折、多轮自适应戏份轻。

### ★ EXP-007 总结

**冷启动世界知识先验在活 agent 里确实省轮（✓ 夜间离线 P@1 结论在真·多轮 agent 的轮数上兑现），但优势温和 + 不均匀**：押对「头条风险」型（UBW/LEGACY）大赢，撞到分散/程序性失效家族（TONG-LAU 的 drainage/gate）反输给零学习的检索秩。salience bias（EXP-005）在活 agent 复现。与全项目「冷启动有限价值、有数据/同源则基线追平」严丝合缝 —— 这次把它从离线 P@1 钉到了在线轮数。
