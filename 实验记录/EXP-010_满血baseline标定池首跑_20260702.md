## 关键发现：第三道闸 = `Obligation.fragment_id` 从不填（已登 DEBT-046）

阅卷对齐键是 `(world_id, fragment_id, coarse_family)`（spec §8.3.1）；truth 侧有 fragment_id，**agent 侧义务的 `fragment_id` 全 None**（`per_fragment_results` 28 条全部 `fragment_id=null → reference=null`）。溯源：
- spec §6.2.2 `Obligation.fragment_id: Optional[str] = None`——字段在，但 **spec 全文没有规定义务如何获得 fragment 归属**；
- `closure/obligation_deriver.py` 从不设置它（fact_binding 支持按 fragment 圈定、validator 会读，唯独派生时不填）。

**性质判定：spec 含糊 + code 未实现的混合层，归属规则是设计决策**（从绑定证据事实的 carrier/target 反推？按 rule_card 作用域×fragment 匹配？），按"没 spec 不写、不接"未擅自实现，登 DEBT-046 待拍板。
